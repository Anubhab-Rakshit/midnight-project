# Meridian — User Feedback

## Overview

This document captures structured feedback from Preprod users of Meridian. Feedback is collected via direct interaction, GitHub issues, and X/Twitter responses.

---

## Feedback Collection

### How to Provide Feedback

1. **GitHub Issues**: [github.com/Anubhab-Rakshit/midnight-project/issues](https://github.com/Anubhab-Rakshit/midnight-project/issues)
2. **X/Twitter**: Reply to [@anubhab_26](https://x.com/anubhab_26)
3. **Direct Message**: Contact via X/Twitter DM
